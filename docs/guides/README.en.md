# Authoring guides

> [English](./README.en.md) · [中文](./README.md)

Grouped by reader task. All of them use public protocols, manifests, and Surface contracts. First-party code has no bypass.

Read these five first:

- [`GETTING_STARTED.md`](GETTING_STARTED.en.md) — start the Host and Web shell from source
- [`PACKAGE_AUTHORING_WALKTHROUGH.md`](PACKAGE_AUTHORING_WALKTHROUGH.en.md) — first third-party Package
- [`INSTALLATION_MODEL.md`](INSTALLATION_MODEL.en.md) — Work / Workspace / Installation model plus install, update, and remove
- [`RUN_LIBRARY.md`](RUN_LIBRARY.en.md) — start and stop Runs
- [`SECRET_MANAGEMENT.md`](SECRET_MANAGEMENT.en.md) — `secret_ref` and API keys
